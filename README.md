# 🛍️ Product Listing App

A clean and responsive web application that fetches and displays products dynamically from a public API. This project demonstrates API integration, asynchronous JavaScript, and dynamic UI rendering using Vanilla JavaScript.

---

## 🌐 Live Demo

👉 https://api-quotes-three.vercel.app/

---

## ⚙️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API

---

## ✨ Features

- 🛍️ Fetch and display products dynamically
- ⚡ Fast and lightweight performance
- 🔄 Real-time data fetching using API
- 🧩 Clean and structured product card UI
- 💰 Display product price, category, and image
